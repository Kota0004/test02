## 災害アプリ「みずみち」について

2026年8月の千葉豪雨で、冠水した道路に気づかず進入した車が多数動けなくなったことを受けて検討している、
**冠水道路アラートアプリ**の企画・設計一式です。

- 地点ごとに「冠水しはじめる時間雨量」の閾値を持たせ、リアルタイム雨量と突き合わせて危険度を出す
- 降水量でのフィルタ(「この雨量ならどの道が危ないか」)と、現在地に応じたアラート
- 動くプロトタイプと、実データを取り込むためのツール一式(検証つき)を同梱
- 手順 → [`災害アプリ/はじめかた.md`](災害アプリ/はじめかた.md) ／ 全体像 → [`災害アプリ/README.md`](災害アプリ/README.md)

## レポート課題の概要(提出期限 2026-07-14)

A4用紙4枚にまとめ、スキャンしたPDFを提出。**著書・論文・ホームページ等の出典を明記すること**が条件。

1. **3つのスピン1/2の合成** — 全角運動量の固有状態を求める。
2. **磁場 $B$(z方向)中の水素2p状態のエネルギー** — 1次摂動(ゼーマン効果)で求める。
3. **以下から1テーマを選択して論述**(要出典):
   - (1) 位置を誤差0で測定しつつ運動量も測定できるか(不確定性原理)
   - (2) トンネル効果を利用したスイッチングデバイスと集積回路の集積度の限界
   - (3) プランク定数の値が2倍の世界について論じる

> 答案ドラフトは [`レポート/量子力学II_レポート.md`](レポート/量子力学II_レポート.md) を参照。
