# 09. 運用コスト

作成日: 2026-08-22

**現在の構成は、すべて無料枠に収まる。** ただし条件と落とし穴があるので記録しておく。

---

## いま使っているもの

| サービス | 用途 | 費用 | 条件 |
|---------|------|------|------|
| **GitHub Actions** | 雨量の自動取り込み・テスト | **無料・無制限** | **public リポジトリ**であること（標準ランナー） |
| **GitHub Codespaces** | iPadからの開発 | **無料枠内** | 月 **120コア時間**（2コアで約60時間）＋ 15GBストレージ |
| **GitHub Pages** | アプリの公開（任意） | **無料** | public リポジトリ |
| 気象庁（アメダスJSON） | リアルタイム雨量 | **無料** | 公式APIではない。出典表示。過度なアクセスは避ける |
| 国土地理院（地図・標高・住所検索） | 地図表示、窪地判定、座標化 | **無料** | 出典表示が必要 |
| OpenStreetMap（Overpass API） | 位置の補正 | **無料** | ODbL。コミュニティ運営なので**大量取得しない** |

## ⚠️ 落とし穴3つ

### 1. private にすると Actions が有料枠になる

無料・無制限なのは **public リポジトリ**だから。private に変えると
無料枠は月2,000分になり、毎時実行（月約720回）だけで使い切りかねない。

**private にするなら、`update-risk.yml` の実行間隔を落とす**こと（例: 6時間ごと）。

### 2. 60日放置でスケジュール実行が止まる

GitHub は、public リポジトリで**60日間動きがない**とスケジュール実行を自動で無効化する。
防災アプリが気づかないうちに止まっているのは困るので、
`keepalive.yml` が月1回コミットして活動があることにしている。

止まってしまった場合は、Actions のページから手動で再開できる。

### 3. 外部サービスへの負荷は「無料だから使い放題」ではない

- **観測点表**（約1MB）は7日キャッシュする。毎時取りに行くと月720MBの無駄になる
- **Overpass API** はコミュニティ運営。範囲を一括で1回だけ取得し、結果をリポジトリに保存して使い回す
- **地理院タイル**は利用規約に「大量アクセスを避ける」旨がある。標高の取得は1回きりで、結果を `dz` として保存する
